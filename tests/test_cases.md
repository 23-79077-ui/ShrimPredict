# ShrimPredict Evaluation Test Cases

This manuscript-ready matrix is based on the current React routes, PHP API
handlers, Flask inference service, and model/data artifacts in this workspace.
Performance thresholds are deliberately left to the study protocol: the
repository does not define latency, FPS, RAM, MAE, or accuracy acceptance
thresholds. Preregister thresholds and keep the same held-out data, server
configuration, and workload for every comparison.

The Selenium script requires a local browser and
`python -m pip install -r tests\requirements.txt`. Set the role-specific
`SHRIMPREDICT_CARETAKER_EMAIL` / `SHRIMPREDICT_CARETAKER_PASSWORD` and
`SHRIMPREDICT_ADMIN_EMAIL` / `SHRIMPREDICT_ADMIN_PASSWORD` variables for
authenticated workflows. Farm-record writes and scan submissions are disabled
unless `SHRIMPREDICT_UI_WRITE_TESTS=1` is explicitly set.

## Evaluation data and interpretation notes

- `ml/artifacts/test_clean.csv` is the in-workspace labeled image manifest. Its
  labels include `Healthy`, `WSSV`, `Black Gill`, and `WSSV + Black Gill`; its
  current model metadata describes three output classes. The evaluator therefore
  computes the requested binary WSSV-vs-non-WSSV confusion matrix and explicitly
  maps the combined label to WSSV-positive. Keep that mapping fixed when
  comparing runs.
- The current backend feed-monitoring route records feed amounts and derives
  pond feed totals. The repository does not include paired automated-vs-manual
  feed ground truth in a standard evaluation CSV. Prepare it from study records;
  do not treat ordinary entered feed quantities as independent model estimates.
- `harvest_predictions.php` implements a baseline of 11,000/15,000 kg harvest
  per kg feed, with adjustments. It does not implement a regression model or
  produce a predicted harvest date. MAE/RMSE/R² and date metrics require
  independent historical outcomes.
- Disease API inference failures and image-quality rejections reduce coverage
  and are listed in the JSON report. Do not silently discard these when
  interpreting accuracy.
